# Тестовое задание: генерация комбинаций и сохранение в MySQL

## Цель
Создать API на Node.js и MySQL, которое генерирует комбинации из списка элементов и сохраняет их в базу данных. API должно соблюдать правило: элементы, начинающиеся с одной и той же буквы, нельзя объединять в одну комбинацию.

## Описание задачи
Дан список элементов разных типов. Каждый тип элемента обозначается буквой-префиксом, и элементы с одинаковым префиксом (одинаковой начальной буквой) нельзя выбирать вместе в одной комбинации. Ваша задача - создать API, которое принимает список чисел, описывающих типы элементов, и требуемую длину комбинации, генерирует все допустимые комбинации, сохраняет их в базу данных MySQL и возвращает результат в ответе.

### Пример входных данных
Дан входной массив, например `[1, 2, 1]`, которому соответствуют элементы `A1`, `B1`, `B2`, `C1`. Условие: никакие два элемента с одинаковой начальной буквой (префиксом) не могут входить в одну комбинацию.

При длине комбинации 2 допустимыми будут следующие комбинации:
```plaintext
["A1", "B1"], ["A1", "B2"], ["A1", "C1"],
["B1", "C1"], ["B2", "C1"]
```
### Задача по API

Создать POST-запрос, который принимает входной массив (например, `[1, 2, 1]`) и длину комбинации (например, 2).
API должно сгенерировать допустимые комбинации и сохранить их в базу данных MySQL.
Каждая комбинация должна быть связана с уникальным ID.

### Требования

### Запрос:
* POST `/generate`
* Тело запроса:
```json
{
  "items": [1, 2, 1],
  "length": 2
}
```

### Схема базы данных
* MySQL (без ORM)
* Вставка данных должна выполняться с использованием транзакций MySQL.
* Должны быть созданы следующие таблицы:
  * `items`: хранит элементы (например, `A1`, `B1` и т.д.).
  * `combinations`: хранит сгенерированные комбинации с их уникальными ID.
  * `responses`: хранит ответы, отправленные клиенту.

### Ответ

API должно возвращать сохранённые комбинации с их уникальными ID в следующем формате:

```json
{
    "id": 1, 
    "combination": [ 
        ["A1","B1"], ["A1", "B2"], ["A1", "C1"],
        ["B1", "C1"], ["B2", "C1"]
    ]
}
```

### Правила

* Элементы с одинаковой начальной буквой (например, `A1` и `A2`) нельзя объединять в одну комбинацию.
* Вставка данных в базу должна выполняться внутри транзакций MySQL для обеспечения согласованности данных.

### Критерии оценки

1. **Корректность**: API должно возвращать правильные комбинации и сохранять их в базу данных.
2. **Проектирование базы данных**: элементы, комбинации и ответы должны храниться в отдельных таблицах.
3. **Использование транзакций**: операции вставки должны быть обёрнуты в транзакции MySQL.
4. **Качество кода**: код должен быть чистым, модульным и хорошо задокументированным.
5. **Эффективность**: операции с базой данных и генерация комбинаций должны выполняться эффективно.

### Дополнительная информация

* Для подключения к MySQL можно использовать [mysql2](https://www.npmjs.com/package/mysql2).
* Не используйте ORM, работайте только с «сырыми» SQL-запросами.
